# 工作台与路由

应用入口位于 `src/main.js`，`App.vue` 挂载分子背景和工作台。背景由 components 内的组件与 workers 内的渲染线程负责；浏览器缺少所需能力时保留静态底色。工作台的响应式布局、导航滑块和滑页动效位于 layouts 与 style.css。

config/platform.js 是品牌、菜单顺序与路由定义的共同来源。每项包含唯一 name、path、label 和页面加载函数。router 根据配置生成路由，未知路径返回首个入口。菜单顺序决定滑动方向。浏览器启用减少动画时页面直接切换。

业务页面放在 views，共用界面放在 components。接入接口时在 services/ 维护请求，在 composables/ 管理可复用的 Vue 状态。如需统一处理接口数据，在 models/ 定义转换规则。这些目录随实际用途创建。

## 验收

在随手记输入草稿，切到使用指南，然后浏览器后退。导航、地址和标题应同步，草稿仍在。直接刷新第二个页面确认部署路径和服务器回退正确。缩窄窗口验证导航仍可操作。正式接入身份后，切换用户时应重建工作台，避免复用上一个用户的缓存。
